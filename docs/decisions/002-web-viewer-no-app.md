# ADR 002: Web Viewer Instead of Second App for Family

**Decision:** Family/trusted contacts receive a private URL (`accion.app/watch/[token]`) — no app download required.

**Why:** Requiring family to download an app adds friction at the worst moment (emergencies). A web link opens instantly in any browser, no account needed.

**Trade-off:** Web viewer has fewer capabilities than a native app (no push notifications). Acceptable — the SMS alert itself is the notification.
