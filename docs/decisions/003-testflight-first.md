# ADR 003: TestFlight Before App Store

**Decision:** Distribute via iOS Simulator and TestFlight before pursuing App Store listing.

**Why:** App Store requires $99/yr Apple Developer Program. TestFlight allows real-device testing with trusted community members in LA without upfront cost. Iterate on feedback before paying for review.

**When to revisit:** Once the core SOS flow is validated with ~10 real testers, enroll in Apple Developer Program and submit for App Store review.
