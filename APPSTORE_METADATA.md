## Review Notes for Apple

**For Apple Reviewer:**

Acción is a privacy-focused location sharing app designed for personal safety. Here's what reviewers should know:

1. **Location Permission:** App requests "When In Use" location permission. Location data is shown locally on the device map and synced to Supabase backend only with user consent.

2. **Anonymous Auth:** The app uses Supabase anonymous authentication. No personal information (email, password, name) is required to use the app.

3. **Data Usage:** Location coordinates, accuracy, and timestamp are stored on Supabase (EU servers). Row-Level Security policies ensure users can only access their own data.

4. **SOS Button:** Holding the button for 3 seconds triggers an emergency alert. This is a local action; alerts to contacts are handled by backend (future feature).

5. **Contacts Permission:** App requests contacts permission only for the SOS feature. Contacts are stored locally and never sent to backend without user action.

6. **No Ads/Tracking:** The app contains no third-party analytics, tracking pixels, or ads.

7. **Testing Instructions:**
   - Grant location permission when prompted
   - Observe location updating on the map
   - Add a test contact via Contacts permission
   - Hold SOS button for 3 seconds to test emergency trigger
   - Check network tab for Supabase sync

8. **Privacy Policy:** Available at [your URL] and included in submission materials.
